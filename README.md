# Beer Servings Dataset Analysis

## Overview
This project explores global alcohol consumption patterns using the Beer Servings dataset. The dataset contains information about beer, spirit, and wine consumption, along with total litres of pure alcohol consumed per person across different countries. The analysis includes data preprocessing, exploratory data analysis (EDA), visualization, and correlation studies.

## Dataset Information
The dataset contains alcohol consumption statistics for 193 countries with the following features:

| Column | Description |
|----------|-------------|
| country | Country name |
| beer_servings | Average beer servings per person |
| spirit_servings | Average spirit servings per person |
| wine_servings | Average wine servings per person |
| total_litres_of_pure_alcohol | Total litres of pure alcohol consumed per person |
| continent | Continent of the country |

## Objectives
- Analyze alcohol consumption patterns across countries.
- Compare alcohol consumption among continents.
- Identify relationships between beverage types and total alcohol consumption.
- Visualize country-wise and continent-wise consumption trends.
- Determine top alcohol-consuming countries.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
### Data Preprocessing
- Checked missing values.
- Handled duplicates.
- Detected and analyzed outliers.
- Prepared data for visualization.

### Exploratory Data Analysis
- Distribution of countries by continent.
- Alcohol consumption trends across continents.
- Correlation analysis using heatmaps.
- Scatter plots for beer, wine, and spirit servings versus total alcohol consumption.
- Top 10 countries by alcohol consumption.

## Key Findings
- Beer consumption shows the strongest positive relationship with total alcohol consumption.
- Europe has the highest average alcohol consumption among continents.
- Belarus ranks among the highest alcohol-consuming countries in the dataset.
- Countries with higher beer, wine, and spirit servings generally have higher total alcohol consumption.
- Alcohol consumption patterns vary significantly across continents.

## Data Source
The dataset originates from FiveThirtyEight's alcohol consumption analysis and is based on World Health Organization (WHO) alcohol consumption statistics.
